# Магазин бабушки · Дубравка

Браузерный 3D-симулятор деревенского магазина от первого лица на **HTML5 + Three.js**.
Вы приезжаете на автобусе в деревню Дубравка, чтобы вернуть к жизни заброшенный магазин бабушки:
знакомитесь с поставщиками, наводите порядок, закупаете и раскладываете товар, обслуживаете покупателей
на кассе, растите уровень, репутацию и ассортимент. Игра полностью на русском; все модели сделаны в коде
и экспортируются в GLB.

## Быстрый старт

```bash
npm install
npm run dev        # открыть http://localhost:5173
```

`npm run build` — проверка типов, экспорт моделей в GLB (`public/assets/models`) и сборка в `dist/`.
`npm test` — юнит-тесты правил, `npm run e2e` — бот-тестировщик в браузере (при запущенном dev-сервере).

## Управление

| Клавиша | Действие |
|---|---|
| W A S D, Shift, Ctrl | ходьба, бег, присесть |
| Мышь | обзор |
| E | взаимодействовать: взять, поставить, поговорить, цена |
| ЛКМ (удерживать) | основное действие: открыть коробку, положить товар, оторвать доску, мести, пробить товар |
| ПКМ | вернуть товар в коробку, отмена |
| 1 / 2 | руки / метла |
| Tab | планшет (время не останавливается) |
| R | повернуть мебель при расстановке |
| Esc | пауза / закрыть окно |

Все клавиши переназначаются в настройках.

# Управление

Все действия переназначаются: **Настройки → Мышь и клавиатура**.

| Действие | По умолчанию | Примечание |
|---|---|---|
| Движение | W A S D | |
| Обзор | мышь | чувствительность, инверсия Y |
| Бег | Shift | |
| Взаимодействовать | E | говорить, взять/положить коробку, взять сканер, открыть цену, ответить на звонок |
| Основное действие | ЛКМ | открыть коробку, положить единицу, сканировать, мести (удерживать), снимать доску (удерживать 2 с) |
| Второе действие | ПКМ | вернуть единицу с полки в коробку |
| Руки | 1 | убрать инструмент |
| Метла | 2 | мести — удерживать ЛКМ, камера не блокируется |
| Планшет | Tab | время не останавливается |
| Присесть | Ctrl | защита от Ctrl+W: подтверждение ухода со страницы |
| Пауза / назад | Esc | |
| Повернуть объект | R | при расстановке мебели |
| Подтвердить | Enter | модалки, терминал, расстановка, пропуск сцены |

## Взаимодействие с товаром

```text
E на коробке       → взять
ЛКМ (коробка в руках, закрыта) → открыть
ЛКМ на секции      → положить единицу (≈0.8 с полёта из коробки на полку)
ПКМ на секции      → вернуть единицу в коробку
E                  → поставить коробку (на пол / на складской стеллаж / в зону доставки)
E у контейнера     → выбросить пустую коробку, доски, мусор
E на секции (руки свободны) → цена продажи
```

## Касса

```text
E на сканере → взять сканер; ЛКМ по товару на прилавке → пробить
Карта: E на терминале → «Подтвердить оплату» (Enter)
Наличные: E на деньгах → взять → E на ящике → открыть → выбрать сдачу → «Выдать сдачу»
```

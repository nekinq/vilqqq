# Текущая сборка «Магазин бабушки»

Браузерная 3D-игра от первого лица на **HTML5 + Three.js (r186)**, TypeScript, Vite. Весь текст — на русском.
Все модели сделаны в коде (ModelKit) и экспортируются в GLB; текстуры и вывески — процедурные (canvas).

## Запуск

```bash
npm install
npm run dev            # http://localhost:5173 — главное меню
npm run build          # проверка типов → экспорт моделей в GLB → сборка в dist/
npm test               # юнит-тесты правил (экономика, склад, день)
npm run e2e            # QA-бот в браузере (нужен запущенный npm run dev)
npm run models         # только экспорт GLB (public/assets/models + manifest.json)
npm run asset-table    # таблица ассетов в Docs/AssetBriefs.md
```

Полезные параметры URL: `?autostart=new` — сразу новая игра без интро (`&intro=1` — с интро),
`?quality=low|medium|high` — пресет на эту сессию, `?src=glb|procedural` — откуда брать модели,
`?viewer=asset&id=shop_shell` / `?viewer=grid&cat=character` — просмотрщик моделей,
`?scene=village` — превью деревни, `?test` — режим автотестов.

## Что реализовано

### Мир
- Деревня Дубравка по MAP-01/MAP-03: площадь с дубом и клумбами, грунтовые дороги и брусчатка (шейдер-сплат),
  5 подворий поставщиков (BLD-01), 10 жилых домов с дворами и заборами, остановка, лес и горы на фоне.
- Low-poly стиль: ступенчатые крыши рядами черепицы, фахверк, ставни, ящики с цветами, фонари.
- Смена дня и ночи по игровому времени, небо с облаками и звёздами, туман, IBL.
- Коллизии (круги и боксы с сеткой), платформы (крыльцо, ступени), автодвери.
- Жизнь фона: дым из труб, птицы над площадью, коровы в загоне.

### Магазин и реставрация (SHOP-00/01)
- Зал, склад, навес доставки (12 мест на 3 поддонах), контейнер для мусора.
- Реставрация обязательна перед первой сменой: 6 досок на витринах (удерживать ЛКМ 2 с → упадёт → E взять до 3 → контейнер),
  4 паутины (метла), 4 мешка мусора (E, до 2 → контейнер), 4 пятна (метла).
- После уборки: новая вывеска, исчезает сухая трава, ночью горят лампы в зале и на крыльце.
- Магазин растёт с уровнем (VisualPlan): вазоны → доска у входа и ящики с цветами под витринами (ур. 2) →
  скамейка и кашпо (ур. 3) → гирлянда-лампочки (ур. 4) → бочки с цветами и коврик (ур. 5) → флажки (ур. 6).
- Табличка на двери «Открыто/Закрыто» переворачивается по фазе дня.

### Поставщики
- 5 продавцов-персонажей у прилавков: первая встреча — диалог (реплики из сюжета), дальше короткое приветствие и каталог.
- Каталог (UI-02): товары с замками и причинами («Нужен уровень», «Нужна лицензия», «Нужен холодильник»),
  степпер коробок, итог, «Доставка включена». Нет мест — отказ без списания денег.
- Дистанционный заказ с планшета — с уровня 4 и после знакомства со всеми пятью.

### Товар, мебель, цены
- 17 товаров, коробка = 8 шт. Коробку: E — взять, ЛКМ — открыть, ЛКМ на полке — положить единицу
  (анимация 0.8 с, единица не масштабируется), удержание ЛКМ — подряд, ПКМ — вернуть в коробку, E — поставить на пол.
- Секция = один товар, 8 мест; несовместимое хранение запрещено с понятной причиной.
- Мебель: стеллаж (18 секций), складской стеллаж (8 мест под коробки), холодильник, морозильный ларь.
  Покупка в планшете, расстановка с призраком, поворотом (R), привязкой к сетке, проверкой проходов
  (вход → касса и доступ ко всем секциям по навигационной сетке), перестановка установленной мебели.
- Цена: [E] на полке — закупка, текущая, новая цена (1–9999), наценка к закупке.

### Касса (без кнопки «Продать»)
- Покупатель выкладывает товар; игрок берёт сканер и пробивает каждую позицию ЛКМ; экран кассы показывает чек.
- Карта — подтвердить на терминале. Наличные — взять купюры с прилавка, открыть ящик, собрать сдачу номиналами;
  «Выдать сдачу» активна только при точной сумме.
- Кассир (уровень 3, найм 250, 25 за смену) сам обслуживает очередь, не перехватывая начатую игроком продажу.

### Покупатели
- 5 типажей × 3 варианта (CHAR-01), процедурная анимация (шаг, дыхание, рука к полке, корзина с товаром).
- Приходят по дорогам деревни (граф дорог), решают войти по чистоте, ходят по залу по навигационной сетке A*,
  резервируют товар, решают о цене (скрытая формула), стоят в очереди (до 4), теряют терпение, платят и уходят.
- Одно итоговое изменение репутации за визит; следы, земля и бумажки на полу; облачка реплик.

### День, экономика, прогрессия
- Подготовка — часы стоят; смена 08:00 → 23:00 (1 с = 1 мин); досрочное закрытие без прыжка времени.
- Итог дня (UI-02): Прибыль = Выручка − Себестоимость − Зарплаты; движение денег; «Начать новый день» срабатывает один раз.
- XP и уровни 1–6, лицензии покупаются (уровень лишь открывает), репутация 0–100, чистота 0–100.
- Старт 350; первая закупка 180 + 32 + 24 + 16 → 98 (проверяется ботом).

### Интерфейс
- HUD (UI-01): день/время/фаза, цель обучения, баланс, уровень, репутация, прицел, одна подсказка, слоты, маркер цели.
- Планшет (Tab, время идёт): Сводка, Развитие, Оборудование, Сотрудники, Поставщики.
- Главное меню с живым фоном, пауза, настройки (графика, звук, клавиши с переназначением, автосохранение).
- Иконки товаров рендерятся из тех же 3D-моделей.

### Сохранения
- IndexedDB: 3 слота + автосохранение (каждые 10 минут игры и в начале дня, отключаемо).
  Сохраняются только данные (без объектов three.js), мир пересобирается при загрузке; версия схемы и миграции.

### Сюжет
- Интро ≈36 с (автобус, пролёт над деревней, остановка), пропуск — Enter/кнопка.
- Звонок бабушки с субтитрами (телефон в руке), обучение из 14 шагов с маркером, +20 XP один раз.
- Финал: уровень 6 и репутация ≥ 80 три дня подряд → звонок бабушки → титр → свободная игра.

### Звук
- Всё синтезируется WebAudio: шаги по дереву/земле, коробки, сканер, касса, монеты, колокольчик двери, телефон,
  метла, уровень; птицы днём, сверчки ночью, ветер; тихая фоновая музыка. Громкости в настройках.

### Графика
- Пресет «Низкое»: прямой рендер с MSAA холста, без теней — для слабых ПК.
- «Среднее»/«Высокое»: сцена в HDR-цель с MSAA 4× (чёткие края без «мыла»), SSAO в половинном разрешении
  с билатеральным размытием, bloom (ночью сильнее — фонари и окна), тонмаппинг Neutral, тёплая цветокоррекция,
  виньетка, дизеринг и адаптивная резкость (CAS).
- Мягкие тени: PCF на 16 выборок по диску Фогеля (патч шейдера), карта 2048/4096, привязка к текселю.

## Производительность
- Статика деревни в BatchedMesh (≈100–150 вызовов отрисовки), товары — InstancedMesh по SKU.
- Модели в GLB со сжатием meshopt (≈6 МБ на 127 моделей вместо 27 МБ).

## Проверка
- `npm test` — 30 юнит-тестов правил.
- `npm run e2e` — бот проходит обучение и первый день действиями игрока и проверяет правила (см. `tools/e2e/run.mjs`).

## Известные ограничения
- В браузере без аппаратного ускорения (программный рендер) игра очень медленная.
- Озвучки голосов нет (громкость «Голоса» зарезервирована).

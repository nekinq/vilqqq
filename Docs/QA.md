# Критерии качества (QA)

## Автоматические проверки

- `npm run typecheck` — без ошибок TypeScript (strict).
- `npm test` — юнит-тесты сервисов (vitest):
  - экономика: старт 350; 180+32+24+16 → 98; отказ в заказе без денег/мест — баланс не меняется;
  - леджер: Прибыль = Выручка − Себестоимость − Зарплаты; себестоимость не списывается дважды; сверка с балансом;
  - сток: нет дублей/потерь при раскладке, возврате, резерве, отмене, уходе покупателя; инварианты секций;
  - касса: сумма, сдача, точная выдача, кассир не перехватывает ручную сессию;
  - прогрессия: пороги XP, уровень не падает, +20 за обучение один раз, лицензии не выдаются уровнем;
  - репутация: одна главная проблема за визит; границы 0–100;
  - чистота: веса грязи, пороги входа;
  - расписание: число визитов по уровню/репутации, распределение по 900 с, лимит одновременных;
  - сейв: snapshot → JSON → restore даёт идентичное состояние; миграция версий;
  - «Начать новый день» — повторный вызов не увеличивает день.
- `npm run e2e` — Playwright в Chromium: загрузка, новая игра с пропуском интро, бот проходит день 1
  (реставрация → стеллаж → закупка → раскладка → смена → обслуживание → отчёт), скриншоты ключевых экранов,
  отсутствие ошибок в консоли.

## Ручной чек-лист

| Область | Проверка |
|---|---|
| Управление | WASD/мышь/E/ЛКМ/ПКМ/1/2/Tab/Ctrl/Esc/R/Enter работают и переназначаются; инверсия Y |
| Камера | при метле, сканере, коробке камера свободна; курсор отпускается только в UI |
| Коробки | взять/открыть/положить/вернуть/поставить/выбросить; 0.8 с анимация, без смены масштаба |
| Хранение | молоко нельзя на обычную полку, стейки только в морозильник, сгущёнка — на полку |
| Поставщики | [E] Поговорить → диалог → каталог; причины блокировки; отказ при 12/12 местах без списания |
| Покупка во время смены | время не останавливается |
| Покупатели | ≤ лимита одновременно, очередь до 4, не застревают, уходят после 23:00 |
| Касса | сканер, карта, наличные со сдачей; без кнопки «Продать» |
| Грязь | следы/земля/бумажки появляются, метла убирает в радиусе ~0.95 м от щётки, не издалека |
| Реставрация | 6/4/4/4; доска — удержание 2 с со сбросом при отпускании; смену нельзя открыть до конца |
| День | подготовка 08:00 (часы стоят), смена 900 с, ранее закрытие не прыгает к 23:00, отчёт один раз |
| День/ночь | плавный переход, ночью фонари и окна, играть комфортно |
| Сейвы | 3 слота + автосейв 600 с (отключаемый); загрузка восстанавливает коробки, сток, мебель, покупателей, кассу |
| Пауза | всё замирает, предмет в руках и касса сохраняются |
| Финал | ур. 6 + репутация ≥ 80 три дня подряд → звонок бабушки → свободный режим |

## Производительность

Medium, 1920×1080, средний ПК: ~60 FPS на площади днём и в полном магазине с 5 покупателями;
≤ 250 draw calls; нет утечек при смене дней (heap стабилен за 5 дней); загрузка < 5 с.

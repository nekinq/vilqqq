# Концепция — «Магазин бабушки» (Дубравка)

## Питч

Браузерный 3D-симулятор деревенского магазина от первого лица (Three.js / WebGL).
Игрок приезжает на автобусе в деревню **Дубравка**, чтобы принять заброшенный магазин
своей бабушки (Нина Петровна). Нужно познакомиться с соседями-поставщиками, расчистить
и восстановить лавку, закупить первый товар, открыть смену, обслуживать покупателей
и постепенно превратить пустую развалину в самый популярный магазин деревни.

> Приехать в уютную деревню, вернуть к жизни бабушкин магазин, лично познакомиться
> с жителями, руками разложить товар, обслужить покупателей на кассе, держать зал в
> чистоте — и увидеть, как маленькая лавка снова наполняется людьми.

## Столпы

| Столп | Что это значит в игре |
|---|---|
| **Всё руками** | Коробки, раскладка по одной единице, сканер, терминал, ящик со сдачей, метла. Никаких кнопок «Продать». |
| **Живая деревня** | Поставщики стоят у своих домов, покупатели идут по дорогам, вечером зажигаются фонари и окна. |
| **Видимый прогресс** | Магазин меняется: доски → чистые окна, пустой зал → полные стеллажи, сухая трава → цветы. |
| **Честная экономика** | Игрок сам назначает цены и учится на результатах. Нет «идеальной цены» и магических процентов. |
| **Браузер прежде всего** | Мгновенный старт, ~60 FPS на среднем ПК, лёгкие low-poly ассеты. |

## Основной цикл

```text
Подготовка (08:00, часы стоят)
 → проверить сток → закупить у поставщиков → принять коробки в зоне доставки
 → разложить товар → настроить цены → прибраться
 → Открыть смену (08:00 → 23:00, 900 реальных секунд)
 → покупатели ищут товар → игрок докладывает, убирает, пробивает на кассе
 → (можно сходить к поставщикам прямо во время смены — время не стоит)
 → Закрытие (новые не приходят, текущие дообслуживаются)
 → Итог дня → улучшения / лицензии / оборудование → новый день
```

## Цель и финал

- Сюжетная цель: **уровень 6** и **репутация ≥ 80** в конце дня **3 дня подряд**.
- Бабушка звонит и поздравляет, затем игра продолжается в свободном режиме.

## Рамки первой версии (не делаем)

Рыбалка, полноценное фермерство, управляемые машины, большой открытый мир, сезоны,
интерьеры всех домов, несколько городов, порча продуктов, продвинутые работники,
полная озвучка. Возможные расширения позже: уборщик, грузчик, озвучка, события, новые товары.

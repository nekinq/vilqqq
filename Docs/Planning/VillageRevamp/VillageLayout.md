# Планировка деревни Дубравка

Референсы: `Docs/Visual/VillageRevamp/Map/MAP-01_overview_labeled.webp` (вид сверху, север вверху),
`MAP-03_northeast_view.webp` (перспектива). Соотношение сторон референса 1339×1174 ≈ 128×112 м —
карта снята «в масштабе» игровой зоны, координаты ниже сняты с неё и подогнаны под геймплей.

## Система координат

- Единица — метр. **X → восток**, **Z → юг**, **Y → вверх** (север = −Z, как «вперёд» в Three.js).
- Игровая зона: X ∈ [−64, 64], Z ∈ [−56, 56] (128 × 112 м). За ней — лес, холмы, горы (не проходимо).
- Земля на высоте 0. Пол магазина, крыльцо и навес доставки — 0.3 м (две ступени).

## Дороги (грунтовые, ширина 4–5 м)

- Кольцо площади (брусчатка) R 8.5…16.
- Юго-запад: площадь → (−22, 0) → остановка (−25, 18) → (−40, 40) → край карты (автобус).
- Юго-восток: площадь → (16, 2) → (23, 14) → (14, 32) → (2, 56) (юг).
- Запад: площадь → бакалея → (−64, −16).
- Северо-запад: площадь → пекарня → (−38, −56).
- Север: площадь → прилавок овощей.
- Северо-восток: площадь → молочная ферма → (30, −56).
- Восток: площадь → мясная лавка → (64, −15).
- Перед магазином — мощёный двор от кольца площади до крыльца.

## Навигация

- **Снаружи**: граф дорог (узлы по полилиниям дорог + выходы к прилавкам, домам, крыльцу магазина).
  Жители ходят по дорогам, а не через огороды.
- **Внутри магазина**: сетка 0.25 м с A* и динамическими препятствиями (мебель, коробки на полу).
- Переход «улица ↔ зал» — через узел у входной двери.

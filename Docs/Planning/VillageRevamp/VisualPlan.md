# Визуальный план

## Пайплайн ассета

```text
Концепт (Docs/Visual) → бриф (AssetBriefs.md: id, размеры, пивот, материалы)
 → строитель модели в коде (src/art/models) → npm run models → GLB
 → AssetManager → проверка масштаба и вида в игре (скриншот) → статус verified
```

Статусы: `planned → concept-approved → modeling → exported → integrated → verified → visual-approved`.
Модель не делаем, пока нет референса: если референса нет — сначала короткий бриф с размерами в стиле существующих концептов.

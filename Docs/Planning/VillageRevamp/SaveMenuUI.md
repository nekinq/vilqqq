# Сохранения, меню и интерфейс

Референсы: `Docs/Visual/VillageRevamp/UI/UI-01_hud_tablet.webp`, `UI-02_trade_day_report.webp`.

## Визуальный язык UI

- Плашки цвета крем `#F4EEDF` с тонкой обводкой `#D9CFB8`, скругление 10–14 px, мягкая тень.
- Акцент — тёмно-зелёный `#2F4F3F` (кнопки, заголовки панелей, ключи клавиш), текст `#26322D`.
- Позитив `#2E7D4F`, негатив `#C0392B`, золото `#D5AC64`.
- Шрифты: Roboto Condensed (интерфейс), PT Serif Bold (крупные заголовки: «Магазин бабушки», «День 1 • Итог»).
- Иконки — собственный SVG-набор в одном стиле (контурные, 2 px).

## HUD (только во время игры)

| Где | Что |
|---|---|
| Слева сверху | `[📅 День 1 | 🕘 08:42 | ● Открыто]`; под ней — одна строка цели обучения `[! Обслужите первого покупателя]` |
| Справа сверху | `[👛 Баланс 350]`; под ней `[★ Уровень 1 | 👍 Репутация 50]` |
| Центр | маленький прицел |
| Низ, центр | **одна** контекстная подсказка: `[E] — Взаимодействовать` / `Удерживайте ЛКМ — Убрать` |
| Справа снизу | слоты `[1 Руки] [2 Метла] [Tab Планшет]`; над ними во время оплаты наличными — `Наличные 20 • Сдача 6` |
| Сверху по центру | всплывающие уведомления (≤ 2 одновременно, 3 с) |
| Низ | субтитры диалогов |

## Планшет (Tab) — не останавливает время

Вкладки: **Сводка · Развитие · Оборудование · Сотрудники · Поставщики**.

- **Сводка** — «Магазин бабушки», `День N • Подготовка/Открыто/Закрытие • 08:00`, карточки Баланс / Уровень+XP / Репутация / Чистота, кнопка «Открыть смену» / «Закрыть смену», история дней (компактная таблица).
- **Развитие** — шкала XP до следующего уровня, лицензии (цена, уровень, кнопка «Купить» или причина блокировки), сюжетная цель.
- **Оборудование** — каталог (стеллаж, складской стеллаж, холодильник, морозильник) + «Переставить» для установленного.
- **Сотрудники** — кассир: нанять / уволить, зарплата, статус.
- **Поставщики** — 5 карточек (знакомы / нет, где искать, ассортимент с замками). Блок дистанционного заказа:
  «🔒 Уровень 4 + знакомство N/5» → после выполнения «Открыть каталог» (тот же сервис заказа).

Внизу планшета: «ⓘ Планшет и каталог не останавливают время».

## Модальные окна (UI-02)

- **Каталог поставщика**: иконка и название поставщика, чипы товаров, карточка (изображение, «Коробка: 8 шт.», «Закупка: 4 за единицу», «Цена коробки: 32»), степпер «Коробок − 1 +», «Итого», кнопка «Купить», подпись «Доставка включена». Заблокированные товары — с замком и причиной.
- **Цена продажи**: изображение, «Закупка за единицу», «Текущая цена», поле «Новая цена» (1–9999), «Наценка +3» и «+75%» (только к закупке), «Сохранить» / «Закрыть».
- **Итог дня**: «Финансовый результат» (Выручка, Себестоимость, Зарплата, Прибыль), «Движение денег» (Закупки, Оборудование, Лицензии, Найм, Изменение баланса), «Баланс 350 → 226», клиенты/продажи/XP/репутация/чистота, кнопка «Начать новый день» (срабатывает **один раз**).
- **Терминал**: сумма, «Подтвердить оплату».
- **Денежный ящик**: номиналы 1, 2, 5, 10 (монеты), 20, 50, 100 (купюры), лоток сдачи, «Нужно: 6 • Выбрано: 5», «Выдать сдачу» активна только при точной сумме.

Иллюстрации товаров в UI рендерятся из тех же 3D-моделей (иконки генерируются при запуске).

## Меню

- **Главное**: Новая игра · Продолжить · Загрузить · Настройки · Выход (в браузере «Выход» → титульный экран). Фон — живая сцена деревни с медленным пролётом камеры.
- **Пауза (Esc)**: Продолжить · Сохранить · Настройки · Главное меню · Выход. Пауза останавливает симуляцию, NPC, время; состояние кассы, товара в руках и коробок сохраняется.

## Настройки

| Вкладка | Параметры |
|---|---|
| Графика | пресет Низкие/Средние/Высокие, масштаб рендера 50–100%, полный экран, ограничение FPS (VSync в браузере всегда включён), тени выкл/низкие/высокие, дальность прорисовки, пост-обработка |
| Звук | Общая, Музыка, Эффекты, Голоса (в будущем) |
| Мышь и клавиатура | чувствительность, инверсия Y, переназначение всех действий |
| Общее | автосохранение вкл/выкл |

Настройки — в `localStorage` (`dubravka.settings.v1`).

## Сохранения (браузер)

- **IndexedDB** база `dubravka-saves`, хранилище `saves`: ключи `slot1`, `slot2`, `slot3`, `autosave`.
- Запись: `{ meta: { slot, version, savedAt, day, time, phase, money, level, playTimeSec }, state: GameStateSnapshot }`.
- Автосохранение каждые **600 с** реального неприостановленного времени (отключаемо) + в начале каждого нового дня.
- Сохраняются только **данные** (без объектов Three.js), со стабильными id: день, время, фаза, деньги, уровень, XP,
  репутация, чистота, лицензии, сотрудники, коробки (где лежат, что внутри, открыты ли), секции и сток,
  резервы, цены, мебель и её позиции/повороты, реставрация, обучение, знакомства, грязь, активные покупатели
  (позиция, состояние, список, корзина, место в очереди), сессия кассы, предмет в руках, леджер, история дней.
- При загрузке мир перестраивается из данных. Схема версионируется (`version`) с миграциями.

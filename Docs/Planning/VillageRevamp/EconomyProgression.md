|---:|---:|---|---:|
| 1 | 0 | 8–12 | 3 |

| 5 | 1100 | 32–40 | 5 |
| 6 | 1800 | 40–48 | 5 |

XP: полная покупка **10**, частичная оплаченная **6**, визит без покупки **0**,
обучение **+20** (один раз), чистота ≥ 90 на момент оплаты: **+1** к покупке.
XP не даётся за лицензии, уборку, открытие коробок и заказы. Уровень не снижается.

## Репутация (0–100, старт 50)

На визит применяется **одно** итоговое изменение (главная проблема, без накопления по каждому товару):

| Событие | Δ |
|---|---:|
| Полная покупка | +0.35 |
| Частичная покупка | +0.10 |
| Ушёл без покупки — нужного товара нет | −0.50 |
| Ушёл без покупки — всё слишком дорого | −0.25 |
| Не дождался кассы (терпение кончилось) | −0.50 |
| Отказался войти из-за грязи | −1.00 |
| Жалоба на грязь (вошёл) | −0.25 (не суммируется с другим минусом) |

Число покупателей: `база(уровень) × (0.6 + 0.8 × репутация/100)`.

## Чистота (0–100)

`чистота = clamp(100 − Σвес_грязи × 1.0, 0, 100)`

| Грязь | Вес | Источник |
|---|---:|---|
| Следы | 3 | покупатели (≈35% визитов) |
| Земля/грязь | 5 | покупатели (≈10%) |
| Бумажка | 2 | покупатели (≈12%) |
| Пятно (реставрация) | 8 | старт |
| Паутина (реставрация) | 4 | старт |
| Мешок мусора (реставрация) | 6 | старт |

| Чистота | Вход новых покупателей |
|---|---|
| 85–100 | 100% |
| 60–84 | ~90% |
| 30–59 | ~65%, вошедшие могут пожаловаться |
| 0–29 | не входят (−1.00 репутации каждый) |

## Решение покупателя о цене (скрыто от игрока)

`k = цена / базовая_цена`. Вероятность взять товар: k ≤ 1.0 → 100%; 1.0–1.3 → до 75%;
1.3–1.7 → до 20%; > 2.0 → ~2%. Репутация чуть расширяет терпимость (±10%).
При k < 0.85 покупатель может взять на 1 шт. больше. Игрок видит только закупку,
текущую цену, новую цену и наценку к закупке.

## Учёт дня (леджер)

```ts
openingBalance, revenue, costOfGoodsSold, productPurchases,
equipmentPurchases, licensePurchases, hireFees, wages,
xp, reputationDelta, cleanliness, customersServed, itemsSold, closingBalance
```

- **Прибыль** = Выручка − Себестоимость проданного − Зарплаты (себестоимость не списывается дважды).
- **Движение денег** = Выручка − Закупки − Оборудование − Лицензии − Найм − Зарплаты.
- Товар на складе не считается убытком.

## Ориентир темпа

~10 игровых дней до 6 уровня при аккуратной игре, затем 3 дня с репутацией ≥ 80.
